# Python学習記録（Day 3〜115）

Pythonを学びながら、毎日作成・更新したコードをまとめた学習リポジトリです。

## 最新版：勉強記録アプリ

`day115.py` は、ターミナルで使う勉強記録アプリです。教科と勉強時間の記録、表示、ランキング、日付・教科・時間での検索ができます。

### 実行方法

```bash
python3 day115.py
```

記録データは実行したフォルダの `study.txt` に保存されます。このファイルは個人の学習記録になるため、GitHubには公開していません。

## ファイルについて

- `day3.py` 〜 `day115.py`：学習の各段階で作成したコード
- 一部のファイル名は、複数日分の学習をまとめたものです
- Day 1・2のファイルはこのフォルダにはありません

## 学んだこと

- 変数、条件分岐、繰り返し
- 関数、クラス、ファイル入出力
- 例外処理（`try` / `except`）
- リストの並び替え、検索、ランキング表示
