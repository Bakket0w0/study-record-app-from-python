# Python学習記録（Day 3〜115）

Pythonを学びながら、毎日作成・更新したコードをまとめた学習リポジトリです。

## 最新版：ブラウザで使える勉強記録アプリ

`app.py` は、ブラウザで使えるStreamlit版の勉強記録アプリです。勉強時間の記録、検索、教科別ランキング、Excel・CSVダウンロードができます。

### 起動方法

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

実行するとブラウザが開きます。記録はこのPC内のデータベースへ自動保存されます。バックアップにはExcelまたはCSVをダウンロードしてください。

### 別の端末・Windowsから使うには

このままの起動方法では、このPCでだけ使えます。Windowsやスマートフォンからも常時使える共有版にするには、クラウドのデータベースと公開先を設定して、専用の共有リンクを発行します。共有版では、利用者はSupabaseへのログイン不要です。

## ターミナル版：勉強記録アプリ

`day115.py` は、ターミナルで使う勉強記録アプリです。教科と勉強時間の記録、表示、ランキング、日付・教科・時間での検索ができます。

### 実行方法

```bash
python3 day115.py
```

記録データは実行したフォルダの `study.txt` に保存されます。このファイルは個人の学習記録になるため、GitHubには公開していません。

## ファイルについて

- `day3.py` 〜 `day115.py`：学習の各段階で作成したコード
- 一部のファイル名は、複数日分の学習をまとめたものです
- Day 1・2のファイルはこのフォルダにはありません

- 関数、クラス、ファイル入出力
